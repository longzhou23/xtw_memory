# 有限注意力扩散：方法与实现边界

[返回项目首页](../README.md) · [研究问题与评测设计](RESEARCH_DESIGN.md)

本文从原 README 拆出已有图运算定义、配置和验证边界，未改变算法，也不构成新的实验结果。这里描述的是待验证的候选生成方法，不是经过验证的脑机制模型，也不是端到端学习得到的记忆策略。

## 在读取链路中的位置

当前 HTTP 读取提供 `formed_multiquery`（多线索直接召回）、`graph_expansion`（最佳路径图扩展）和 `attention_diffusion`（有限注意力扩散）三种分支。

三者后续使用共同的重排与候选预算设置，但不因此拥有相同的实际计算成本。扩散分支先执行出现阈值筛选，再进入共同重排；重排器不会补回未通过该阈值的节点。这一差异应纳入消融分析。

## 注意力更新

设节点在第 `t` 步的注意力为 $a_i^{(t)}$，初始种子分布为 $a_i^{(0)}$，且总量归一为 1。关系有效权重 $w_{ij}$ 综合关系强度、关系通道权重与上下文相关性门控。对每条允许传播的弧，先计算传播势与节点总流出量：

$$
p_{ij}=\max(0,a_i^{(t)}w_{ij}-\epsilon),\qquad
 o_i=\min\left(\rho a_i^{(t)},\sum_j p_{ij}\right).
$$

当传播势总和大于 0 时，按比例分配流量；否则该节点流出为 0：

$$
F_{ij}=o_i\frac{p_{ij}}{\sum_k p_{ik}},\qquad
b_j=a_j^{(t)}-o_j+\sum_i F_{ij}.
$$

随后进行幂次竞争，并向初始种子回注：

$$
a_j^{(t+1)}=(1-\alpha)\frac{b_j^\gamma}{\sum_k b_k^\gamma}
+\alpha a_j^{(0)}.
$$

实现检查传播前后注意力总量为 1，并记录每步流量。守恒检查约束图运算行为，不证明选出的节点对当前对话有用。

## 召回入口采用的配置

| 参数 | 当前值 | 作用 |
|---|---|---|
| 流量下限 `ε` | `0.00005` | 传播势计算中的扣除项 |
| 最大流出比例 `ρ` | `0.8` | 限制节点单步流出的注意力 |
| 竞争指数 `γ` | `1.05` | 幂次竞争 |
| 种子回注 `α` | `0.04` | 向初始种子分布回注 |
| 迭代步数 | `12` | 图运算的更新次数 |
| 出现阈值 | `0.004` | 共同重排之前的候选筛选 |
| 温度 | `1.0` | 召回入口配置值 |

这里列的是召回入口采用的覆盖参数；底层动力学模块自身的默认值不同，复现时不能混用。这些是固定实现参数，不是已经通过独立评测确定的最优配置。

## 关系通道与方向

`CAUSAL`（因果关联）通道遵循计划中的方向，`SIMILARITY`（相似）与 `OPPOSITION`（对立）可双向传播。当前 HTTP 默认线索计划仅启用 `SIMILARITY`（权重 1），`CAUSAL` 与 `OPPOSITION` 权重为 0；底层支持这些通道，不代表默认接口会使用它们。

关系标签表达记忆图中的关联，不构成因果识别或因果推断证据。

## 验证与必要对照

已有合成场景只证明读取链路可以执行，尚未证明扩散优于直接召回或最佳路径图扩展。完整评测需要固定形成图、种子规则、重排器与预算，并分别记录候选质量、下游效用和实际耗时。

必要消融包括移除关系、改变关系类型、移除竞争或种子回注，以及改变步数和阈值。参数只在开发集选择，独立验证前冻结配置，避免把多轮调参中的最佳结果当成方法优势。详细方案见 [研究问题与评测设计](RESEARCH_DESIGN.md)。
